# 06. API Notes

## Требования к API
Для MVP внешние API должны:
- быть бесплатными или иметь бесплатный тариф
- отдавать текущую погоду
- отдавать почасовой прогноз
- отдавать прогноз на несколько дней
- отдавать качество воздуха
- поддерживать поиск по координатам или городу

## Временное решение
На этапе проектирования API-провайдер не фиксируется окончательно.
Допускается начать с одного провайдера для погоды и качества воздуха либо с двух отдельных API.

## Требования к интеграции
- сетевой слой должен быть изолирован через repository
- модели API не должны напрямую использоваться в UI
- все ответы должны маппиться в внутренние domain/UI модели

## Ошибки
Нужно предусмотреть:
- отсутствие интернета
- отказ API
- пустой ответ
- неуспешное определение города
- отсутствие доступа к геолокации

# 05. Project Tasks

## Epic 1. Project Setup
- создать Android-проект
- подключить Compose
- настроить базовую архитектуру
- настроить зависимости
- подготовить навигацию
- настроить репозиторий GitHub

## Epic 2. Onboarding and Security
- экран приветствия
- создание PIN
- повтор PIN
- экран ввода PIN
- интеграция биометрии
- хранение флагов первого запуска

## Epic 3. Profile
- экран настройки профиля
- выбор возраста
- выбор пола
- загрузка фото из галереи
- загрузка фото с камеры
- сохранение профиля локально

## Epic 4. Location
- запрос разрешений
- определение координат
- определение города
- ручной ввод города
- сохранение текущего города

## Epic 5. Weather and Air Quality
- выбрать API
- подключить сетевой слой
- реализовать получение текущей погоды
- реализовать почасовой прогноз
- реализовать недельный прогноз
- реализовать получение качества воздуха
- маппинг данных в UI-модели

## Epic 6. Main Screen
- header с городом
- текущая температура
- состояние погоды
- блок качества воздуха
- блок почасового прогноза
- блок недельного прогноза
- оформление day/night состояния

## Epic 7. Stabilization
- обработка ошибок сети
- состояния загрузки
- пустые состояния
- тестирование ключевых сценариев
- улучшение UI

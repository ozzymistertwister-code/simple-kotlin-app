# 01. Product Description

## Название
Температура и качество воздуха

## Формат продукта
Нативное Android-приложение на Kotlin.

## Проблема
Пользователь не всегда быстро понимает:
- какая погода сейчас
- что будет в ближайшие часы
- насколько хорошее или плохое качество воздуха
- насколько комфортна среда для повседневной активности

Существующие погодные приложения часто либо перегружены, либо недостаточно красиво и понятно показывают состояние окружающей среды.

## Решение
Создать Android-приложение, которое объединяет:
- текущую погоду
- ближайший прогноз
- качество воздуха
- понятную визуализацию погодных состояний
- простую персональную настройку

## Целевая ценность
Пользователь должен за несколько секунд получить понятный ответ:
- что происходит с погодой сейчас
- что будет дальше
- насколько воздух безопасен / комфортен
- как это выглядит в наглядной форме

## Целевая аудитория
На старте приложение разрабатывается для ограниченного числа пользователей в пилотном режиме.

## Основной пользовательский сценарий
1. Пользователь впервые открывает приложение
2. Настраивает PIN и при желании биометрию
3. Выбирает параметры профиля
4. Разрешает геолокацию или вручную вводит город
5. Попадает на главный экран
6. Видит текущую погоду, качество воздуха и прогноз

## Ключевые принципы продукта
- быстро
- визуально красиво
- понятно без лишнего текста
- минимум сложных настроек
- локальное хранение пользовательских данных

# 04. User Flows

## Flow 1. Первый запуск
1. Пользователь открывает приложение
2. Видит приветственный экран
3. Создаёт PIN-код
4. При желании включает биометрию
5. Заполняет минимальный профиль
6. Выбирает источник локации:
   - автоматически
   - вручную
7. Переходит на главный экран

## Flow 2. Повторный запуск
1. Пользователь открывает приложение
2. Проходит PIN / биометрическую проверку
3. Попадает на главный экран

## Flow 3. Получение локации
1. Пользователь разрешает доступ к геолокации
2. Приложение получает координаты
3. Определяет город
4. Загружает погоду и качество воздуха
5. Отображает данные

## Flow 4. Ручной выбор города
1. Пользователь переходит в выбор города
2. Вводит город вручную
3. Подтверждает выбор
4. Приложение сохраняет город локально
5. Загружает данные по выбранному городу

## Flow 5. Настройка профиля
1. Пользователь открывает профиль
2. Выбирает возрастной интервал
3. Выбирает пол
4. Загружает аватар
5. Сохраняет изменения

# 02. MVP Scope

## Цель MVP
Сделать первую рабочую версию приложения, которая позволяет пользователю:
- пройти первичную настройку
- защитить вход PIN-кодом
- использовать биометрию
- определить или указать город
- получать и видеть текущую погоду
- видеть прогноз по часам и на неделю
- видеть качество воздуха

## Что входит в MVP

### 1. Первый запуск и onboarding
- экран приветствия
- переход к настройке PIN
- опциональное включение биометрии
- настройка профиля

### 2. Профиль пользователя
- возрастной интервал
- пол
- аватар
- выбор аватара:
  - из галереи
  - из камеры

### 3. Авторизация
- вход по PIN-коду
- хранение PIN локально в защищённом виде
- биометрическая разблокировка при поддержке устройства

### 4. Локация
- автоматическое определение геопозиции
- определение города по координатам
- ручной ввод города
- сохранение выбранного города локально

### 5. Погода
- текущая температура
- ощущаемая температура
- погодное состояние
- день / ночь
- ветер
- осадки
- почасовой прогноз
- недельный прогноз

### 6. Качество воздуха
- текущий показатель качества воздуха
- краткая категория состояния
- визуальное отображение уровня

### 7. Главный экран
- текущая погода
- текущий город
- качество воздуха
- основные погодные показатели
- прогноз по часам
- прогноз на неделю
- визуальные состояния и погодные иллюстрации

## Что не входит в MVP
- регистрация через email / телефон
- backend
- синхронизация между устройствами
- история за длительный период
- виджет на экран
- push-уведомления
- несколько независимых пользователей на одном устройстве
- advanced health analytics

## Критерий готовности MVP
MVP считается готовым, если пользователь может:
1. Установить и открыть приложение
2. Настроить PIN и профиль
3. Разрешить биометрию
4. Выбрать или определить город
5. Получить актуальные данные о погоде и воздухе
6. Увидеть текущую, почасовую и недельную картину

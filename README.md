# Температура и качество воздуха

Android-приложение на Kotlin для отображения текущей погоды, ближайшего прогноза и качества воздуха в красивой и понятной визуальной форме.

## Цель проекта

Сделать простое мобильное приложение, которое помогает пользователю быстро понять:
- какая погода сейчас
- какая погода будет в ближайшие часы и дни
- какое качество воздуха в текущей локации
- насколько комфортна окружающая среда

## Основные функции MVP

- вход по PIN-коду
- поддержка биометрической авторизации
- настройка простого локального профиля пользователя
- определение местоположения автоматически
- ручной выбор города
- загрузка данных о погоде и качестве воздуха из внешних API
- отображение текущей погоды
- отображение прогноза по часам
- отображение прогноза на неделю
- отображение качества воздуха
- красивое визуальное представление погодных состояний

## Технологический стек

- Kotlin
- Android
- Jetpack Compose
- MVVM
- Navigation Compose

- Location Services

## Архитектурный подход

Приложение разрабатывается без backend-сервера.
Все пользовательские настройки и локальные данные хранятся на устройстве.
Внешние данные о погоде и качестве воздуха загружаются из публичных API.

## Статус проекта

Проект находится на стадии проектирования MVP и подготовки базовой Android-структуры.

## MVP-ограничения

В первую версию не входят:
- серверная часть
- облачная синхронизация
- push-уведомления
- multi-user режим
- сложная аналитика здоровья
- виджеты и Wear OS

## Базовый roadmap

1. Зафиксировать продукт и MVP
2. Подготовить Android-проект
3. Реализовать onboarding и профиль
4. Реализовать PIN и биометрию
5. Подключить геолокацию и ручной выбор города
6. Подключить погодный API и air quality API
7. Собрать главный экран
8. Добавить почасовой и недельный прогноз
9. Доработать UI и тестирование
